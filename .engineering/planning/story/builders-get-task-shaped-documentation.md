# Story: Builders get task-shaped documentation

## Outcome

A first-time builder can inspect, run read-only, configure a provider, admit one confined change, operate sessions, and choose advanced features without reading design history.

## Context

The provider and workflow pages mix tutorials, rationale, exact formats, events, and deferred design in single long narratives.

## Acceptance

- Navigation separates Tutorials, How-to guides, Concepts, Reference, and Status.
- Existing routes remain; a new confined-change tutorial and exact provider/workflow references are additive.
- Guides lead with prerequisites, outcome, command, verification, safety, and next step.
- Provider precedence/renewal and workflow schema/events move to reference without losing facts.

## Out of Scope

No hosted service tutorial, MCP guide, custom search, or shared cross-repository theme.

## Open Questions

None.
